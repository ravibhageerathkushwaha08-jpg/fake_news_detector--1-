# Fake News Detector (Beginner Project)

A simple, beginner-friendly Machine Learning project that classifies a news
headline/article as **REAL** or **FAKE** using **TF-IDF** + **Logistic
Regression**.

This is intentionally kept simple (no deep learning, no transformers) so
it's easy to understand as a fresher — but it's a complete, working,
end-to-end ML pipeline: data -> preprocessing -> training -> evaluation ->
prediction.


## Quick Start — Web App (paste a headline in the browser)

The `model/` folder already contains a trained model, so this works right away:

```bash
pip install -r requirements.txt
python app.py
```

Then open your browser at **http://127.0.0.1:5000**, paste in a headline,
and press the "Analyze" stamp button — it'll show a **VERIFIED** or
**FAKE** stamp with a confidence percentage.

## Quick Start — Command Line (no browser)

```bash
pip install -r requirements.txt
python predict.py
```

Then type any headline, e.g.:

```
Enter news text: Scientists reveal secret cure that doctors don't want you to know
--> Prediction: FAKE  (confidence: 91.42%)
```

You can also pass text directly:

```bash
python predict.py "The Reserve Bank of India announced a new policy today"
```

## Retrain the Model Yourself (recommended, to learn the pipeline)

```bash
pip install -r requirements.txt
python train.py
```

This will:
1. Load `data/news.csv`
2. Clean the text (lowercase, remove punctuation/numbers/links)
3. Split into train (80%) / test (20%) sets
4. Convert text into numeric TF-IDF features
5. Train a Logistic Regression classifier
6. Print accuracy, classification report, and confusion matrix
7. Save the model to `model/fake_news_model.pkl` and `model/vectorizer.pkl`

Then run `python predict.py` to test it.

## About the Dataset

`data/news.csv` is a **small synthetic sample dataset** (~600 rows, 300
REAL + 300 FAKE) generated by `generate_dataset.py`. It's built from
sentence templates so that:
- REAL news reads in a factual/formal news style (official statements,
  government bodies, cited sources).
- FAKE news reads in a sensational/clickbait style (miracle cures,
  conspiracy phrasing, "share before it's deleted" type language).

This keeps the project fully self-contained and runnable without any
internet download. It's meant for **learning the pipeline**, not for
real-world fact-checking.

### Using a real dataset instead

For a more realistic project, download the popular Kaggle dataset:
**"Fake and Real News Dataset"**
(https://www.kaggle.com/datasets/clmentbisaillon/fake-and-real-news-dataset)

It has `Fake.csv` and `True.csv`. To use it:
1. Combine both files into one CSV with two columns: `text`, `label`
   (`label` = `FAKE` or `REAL`).
2. Replace `data/news.csv` with this new file (same column names).
3. Run `python train.py` again.

No code changes needed — the pipeline works the same way.

## How It Works (short explanation)

1. **TF-IDF (Term Frequency–Inverse Document Frequency)**: converts each
   piece of text into a vector of numbers representing how important each
   word is to that text relative to the whole dataset.
2. **Logistic Regression**: a simple, fast, and easy-to-interpret
   classification algorithm — great for text classification with TF-IDF
   features and a good starting point before trying more advanced models.
3. **Train/Test Split**: the model is trained on 80% of the data and
   evaluated on the remaining 20% it has never seen, to check it actually
   generalizes rather than memorizing.
